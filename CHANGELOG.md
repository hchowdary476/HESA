# Changelog

All notable changes to the HESA (JARVIS) AI Assistant project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-31

### Added
- **Holographic QML GUI**: Complete PySide6 / QML cyber-aesthetic interface with 6 live monitoring pages.
- **Single-Instance Boot**: Consolidated zero-touch Windows logon auto-start via Registry and Task Scheduler.
- **Hybrid AI Router**: Automatic failover between local Ollama (Phi-3), Gemini, Groq, and offline rules.
- **Voice Pipeline**: OpenWakeWord engine with Silero VAD, Faster-Whisper STT, and Edge TTS.
- **Memory Engine**: Multi-tier persistence (SQLite, JSON, Knowledge Graph) with semantic search.
- **Security Shield**: Fernet key encryption, permission controls, and plugin sandboxing.

### Verified
- 100% PASS on 56 core subsystem audits.
- 0 MB memory leak, 0 thread leak, and 0 process crash during 600-iteration stress testing.
