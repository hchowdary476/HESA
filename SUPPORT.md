## ❓ Getting Assistance

### 1. GitHub Discussions
For general questions, feature discussions, or sharing setups:
👉 Join our [GitHub Discussions](https://github.com/hchowdary476/HESA/discussions)

### 2. Bug Reports
If you encounter a bug:
1. Search existing [GitHub Issues](https://github.com/hchowdary476/HESA/issues) to avoid duplicates.
2. File a new bug report using our issue template, including:
   - OS version and Python version
   - Relevant log snippets from `logs/`
   - Detailed steps to reproduce

---

## 🛡️ Security Vulnerabilities
To report a security issue, please follow our [Security Policy](SECURITY.md) and report privately to `security@open-jarvis.org`.
