## Endpoints

### `GET /api/items`

List all items
> 🔒 **Authentication required.** Include `Authorization: Bearer <token>` header.

**Response (200):**
```json
[
  {"id": 1, "title": "Item 1", "is_completed": false, ...},
  {"id": 2, "title": "Item 2", "is_completed": true, ...}
]
```


### `POST /api/items`

Create new item
> 🔒 **Authentication required.** Include `Authorization: Bearer <token>` header.

**Request Body:**
```json
{
  "title": "My Item",
  "description": "Optional description",
  "is_completed": false
}
```
**Response (201):**
```json
{
  "id": 1,
  "title": "My Item",
  "description": "Optional description",
  "is_completed": false,
  "created_at": "2026-07-01T10:00:00",
  "updated_at": "2026-07-01T10:00:00"
}
```


### `GET /api/items/{id}`

Get item by ID
> 🔒 **Authentication required.** Include `Authorization: Bearer <token>` header.



### `PUT /api/items/{id}`

> 🔒 **Authentication required.** Include `Authorization: Bearer <token>` header.
