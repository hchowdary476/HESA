# ❓ Frequently Asked Questions (FAQ)

### Q1: Is HESA completely free and open-source?
**A:** Yes! HESA is licensed under the MIT License and is 100% open-source software.

### Q2: Can I run HESA completely offline?
**A:** Absolutely. Set `JARVIS_PRIVACY_MODE=true` in your `.env` file and run a local model using Ollama (`ollama pull phi3:latest`). HESA will execute speech recognition, LLM reasoning, and TTS synthesis without sending a single byte to the internet.

### Q3: What platforms are supported?
**A:** HESA is optimized for Windows 10 and Windows 11 (64-bit). Linux and macOS support are on our roadmap.

### Q4: How does HESA compare to commercial desktop assistants?
**A:** HESA provides complete user ownership, zero telemetry tracking, custom ONNX wake word models, open multi-LLM routing, and full Python/QML extensibility.

### Q5: How do I report bugs or request features?
**A:** Please open an issue on our [GitHub Issues](https://github.com/hchowdary476/HESA/issues) page following our template guides.
